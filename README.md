# 재고 조회 시스템 (정식 Web 버전 1차 템플릿)

## 설치
```bash
npm install
```

## 실행
```bash
npm run dev
```
브라우저에서 `http://localhost:3000` 접속.

## 포함 기능
- 상단: 체크박스 2개 + 검색창 + [데이터 조회]/[견적 생성]/[설정 관리]
- 조회 버튼 누를 때만 데이터 로드 (초기 자동 로드 없음)
- 단일 AG Grid
  - 표준 컬럼 12개 고정
  - 헤더/셀(임시) 중앙 정렬
  - 말줄임 + hover 툴팁
  - 컬럼 폭/순서 상태 localStorage 저장/복원 (재접속해도 유지)
- 견적 생성: 선택한 행 기반 텍스트 생성 + 복사

## 실데이터 연결
`app/api/inventory/route.ts`에서 mock 데이터를 실데이터 로더로 교체하면 됩니다.
- 전략구매/일반(현대/기아) 원본 컬럼이 달라도 `normStrategy`, `normGeneral`에서 표준 컬럼으로 정규화하세요.
